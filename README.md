# AI Shorts Studio

AI-assisted pipeline for turning authorized video sources into short-form clips.

## MVP

- FastAPI API
- Temporal workflow orchestration
- PostgreSQL job state
- MinIO/S3 artifact storage
- faster-whisper transcription
- LLM-provider abstraction with heuristic fallback
- FFmpeg rendering with 9:16 output and ASS captions
- Next.js web client

See the architecture and local setup in this README and `.env.example`.
